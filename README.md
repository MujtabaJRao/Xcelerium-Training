# Hardware Design Repository ⚙️
This repository contains my work related to **digital logic design, computer architecture, and hardware description languages**.

### Topics Covered
- Verilog / SystemVerilog RTL designs  
- Digital Logic (adders, muxes, FSMs, counters, shifters)  
- Computer architecture & RISC-V components  
- Self-checking testbenches (directed + randomized)  
- FPGA-oriented designs and simulations  

### Tools
- Verilog / SystemVerilog  
- ModelSim / Questa / Icarus Verilog  
- Intel Quartus  
- Linux  

This repo serves as a **learning log and practice ground** for hardware/RTL development and verification.

Work in progress — continuously updated.
